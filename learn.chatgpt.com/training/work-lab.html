What to know

Using plugins, ChatGPT can gather and synthesize messy information from different sources.

You’re organizing a team dinner. Start a project and find the dinner plan, guest list, restaurant quotes, and schedule.

  1. Select + beside Projects in the sidebar, or open Choose project and select Create project. Choose Cloud and name it Dinner planning to keep your team dinner’s chats and materials together.

  2. Open Plugins in the app sidebar. Add both sample plugins; no account connection is needed in this exercise.

  3. Type @ and choose Google Drive. Ask it to find the dinner plan, guest list, restaurant quotes, and schedule. The practice search returns prepared files without connecting your account.

    @Google Drive Find the documents for our team dinner: the dinner plan, guest list, restaurant quotes, and schedule. Show me the relevant files so I can check them before we plan the meeting.

  4. Review the dinner documents. Check the budget, guest count, and available times before asking for a brief.

Projects and chats

A project keeps related chats, files, and sources together. Use one when several tasks need the same context. Each chat holds a conversation and its results; start a separate chat for each distinct outcome.

Plugins and connected sources

Plugins add tools and reusable skills to ChatGPT. Google Drive and Gmail connect it to files and email you can access. Browse Plugins, review the requested permissions, and connect your account when prompted. Type @ in chat to choose a plugin.
