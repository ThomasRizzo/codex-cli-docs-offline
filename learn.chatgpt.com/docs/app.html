ChatGPT desktop app

Your command center for complex work

Run projects in parallel, work with files, use your computer, and keep long-running work moving from one desktop workspace.

Download for macOS (Apple Silicon)
App quickstart
01

Keep every chat in view

Move between projects and long-running work without losing context.

02

Create and inspect real outputs

Open documents, spreadsheets, images, and other files in the same workspace.

03

Work across your tools

Use the browser, desktop apps, and plugins, or schedule a task inside a chat.

Quickstart

Get started with the desktop app

Install ChatGPT, sign in, choose where to work, and send your first message.

  1. 1

    Install the ChatGPT desktop app

    Download ChatGPT for macOS, Windows, or Linux.

    Download ChatGPT
  2. 2

    Open ChatGPT and sign in

    Open the app, then sign in with your ChatGPT account.

  3. 3

    Choose where to work

    Start a chat, create a project, or open a folder. ChatGPT can use the files and context in the location you choose.

    Learn about chats and projects
  4. 4

    Send your first message

    Choose ChatGPT or Codex. In ChatGPT, use the toggle above the composer to select Chat or Work. In Codex, start with New chat. For a quick question, point to New chat and select the Quick chat icon on its right. Then describe the result you want and add any files or context ChatGPT needs.

    Learn how to use ChatGPT

Use the ChatGPT desktop app when…

Coordinate several projects Keep parallel work visible and move between chats quickly.
