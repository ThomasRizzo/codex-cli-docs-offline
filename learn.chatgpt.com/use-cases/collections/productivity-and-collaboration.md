> For the complete documentation index, see [llms.txt](/llms.txt). Markdown versions of documentation pages are available by appending `.md` to the page URL.

Coordinate work across plugins, data, and teams.

Use ChatGPT Work or Codex to coordinate work across plugins, files, and teams.
ChatGPT can gather context from files, messages, docs, and spreadsheets, then turn it into shareable artifacts.
For data projects that depend on a repository, reproducible scripts, or worktrees, use Codex.
